## Context

Home Essentials (BR-01) launches first in Mexico. This PR adds the quick-quote endpoint to `channel-bff`, so that the new Home Essentials screens can quote in Mexico. It is the first Mexican feature built in `channel-bff` instead of `mx-quote-bff`.

## Changes

- New endpoint `POST /v1/home-quotes` that returns a quick quote with the customer data pre-filled.
- New `SalesforceRatingClient` that calls the Mexican Salesforce org directly for rating and for the customer profile. The Home Essentials Process API does not exist yet and the integration backlog is six weeks long; we will switch to the Process API later.
- Renamed `premiumAmount` to `totalPremium` in `QuoteResponse`, to align with the naming of the Mexican frontend.
- Added the `MX` country configuration and a feature flag for the pilot.

## Testing

- Unit tests added (generated with our coding assistant and reviewed). Coverage of the new code: 80%.
- Tested manually against the Mexican Salesforce development org.

## Rollout

- Mexico pilot only, behind the feature flag.
